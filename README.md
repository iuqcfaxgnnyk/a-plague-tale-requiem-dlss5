## Overview

This mod retrofits NVIDIA DLSS 5 Super Resolution and Frame Generation into A Plague Tale: Requiem, delivering significant performance headroom on high-fidelity settings and ray-tracing presets.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **A Plague Tale Requiem DLSS 5** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
